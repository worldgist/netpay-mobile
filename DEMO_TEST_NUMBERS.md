# Demo Test Numbers for Apple App Review

Quick reference guide for all test numbers needed during app review.

## 📱 Phone Numbers (Airtime & Data)

**Format:** 11 digits starting with 0

**Examples:**
- `08012345678` (MTN)
- `07012345678` (Airtel/Glo)
- `09012345678` (9mobile)
- `08123456789` (Any network)

⚠️ **Note:** The phone number you enter will receive the actual airtime/data. Use a number you can verify.

---

## 🔌 Electricity Meter Numbers

**Format:** 11-13 digits (varies by Disco)

### VTpass Sandbox Test Numbers:
- **Prepaid (Successful)**: `1111111111111` (13 digits)
- **Postpaid (Successful)**: `1010101010101` (13 digits)
- **Pending Transaction**: `201000000000` (12 digits)

### General Test Numbers:
- **IKEDC (Ikeja)**: `12345678901` (11 digits)
- **EKEDC (Eko)**: `98765432109` (11 digits)
- **AEDC (Abuja)**: `11223344556` (11 digits)
- **PHED (Port Harcourt)**: `22334455667` (11 digits)
- **KEDCO (Kano)**: `33445566778` (11 digits)

⚠️ **Note:** Meter numbers vary by Disco. The system will validate before purchase.

## 📺 Cable TV Smart Card/Decoder Numbers

**Format:** 10-11 digits

### Demo Test Numbers:
- **DSTV**: 
  - `1234567890` (10 digits)
  - `1122334455` (10 digits)
  
- **GOTV**: 
  - `9876543210` (10 digits)
  - `2233445566` (10 digits)
  
- **Startimes**: 
  - `4567890123` (10 digits)
  - `3344556677` (10 digits)

⚠️ **Note:** Card numbers must be at least 10 digits. The system validates before purchase.

## 📋 Quick Testing Checklist

✅ **Airtime Purchase**
- Phone: `08012345678`
- Amount: ₦100, ₦500, or ₦1000

✅ **Data Purchase**
- Phone: `08012345678`
- Select any data plan

✅ **Electricity Payment**
- Meter: `1111111111111` (Prepaid) or `1010101010101` (Postpaid)
- Amount: ₦1000, ₦2000, or ₦5000

✅ **Cable TV Subscription**
- DSTV Card: `1234567890`
- GOTV Card: `9876543210`
- Startimes Card: `4567890123`

✅ **Education Services**
- JAMB Profile ID: `0123456789`
- WAEC: Phone optional

## ⚠️ Important Notes

1. **Real Transactions**: These numbers will process real transactions if vendor APIs are in production mode
2. **Sandbox Mode**: If vendors are in sandbox/test mode, transactions won't charge real services
3. **Validation**: All numbers are validated by vendor APIs before purchase
4. **Format**: Ensure numbers match the required format (digits only, correct length)
